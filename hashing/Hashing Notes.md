# Array vs Hash Set vs Hash Map :

1. Lookup:
   - Array Time Complexity: O(n)
   - Hash Set Time Complexity: O(1)
   - Hash map Time Complexity: O(1)
2. Element order:
   - Array - ordered by indices
   - Hash Set - unordered
   - Hash Map - unordered
3. Duplicate Elements:
   - Array can have duplicate elements
   - Hash Set can not have duplicate elements
   - Hash Map can not have duplicate keys (but can have duplicate values)
