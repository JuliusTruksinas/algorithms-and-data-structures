# Terminology

- node = just a container for storing data
- head = the first node in a linked list
- tail = the last node in a linked list

# What is a linked list

- it is a data structure = a way to organize data
- every piece of data (int, string, other object, etc.) is stored in a node
- each node is linked to another node
- the very last node will be linked(pointing) to "nothing", i.e. **null**

# Key Characteristics

- It is an ordered data structure
